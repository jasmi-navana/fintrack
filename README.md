# FinTrack

A full-stack Personal Finance Management System built with:

## Tech Stack
- React.js
- TypeScript
- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication

## Features
- User Authentication
- Income & Expense Tracking
- Financial Goal Planner
- Reports & Analytics
- Profile Management
- CRUD Operations

## Installation

Frontend:
npm install
npm run dev

Backend:
npm install
npm run dev
